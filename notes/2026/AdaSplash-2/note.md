## 摘要 (Abstract)

Sparse attention 提出以缓解 Transformer 的二次计算成本，但 α-entmax attention 因归一化器 τ 的计算开销而滞后于 softmax。AdaSplash-2 通过直方图初始化将 τ 的迭代次数降至 1–2 次，结合稀疏感知 GPU 实现跳过零块，在块稀疏度 >60%（常见于长上下文）时匹配或超越 FlashAttention-2 的每步训练时间。下游任务中，使用 α-entmax 注意力训练的模型在短上下文与 softmax 基线匹配，在长上下文中取得显著收益。

## 研究动机

1. **二次计算瓶颈**：Transformer 的自注意力在长序列上具有二次时间/内存复杂度，FlashAttention 解决了这一问题但 attention 仍是密集的
2. **α-entmax 的优势与问题**：
   - α-entmax 是 softmax 的可微分稀疏替代，能产生输入依赖的精确零值
   - 在长上下文泛化上优于 softmax
   - 但归一化常数 τ 需要迭代求解，计算开销大
3. **AdaSplash 的不足**：前代 AdaSplash 仍需要多次 pass 来计算 τ，且块掩码策略效率不高

## 方法

### 1. 核心思想：直方图初始化

**关键创新**：在 SRAM 上构建紧凑的 attention scores 直方图，提供 τ* 的高质量初始估计，使后续求解器在 1–2 次迭代内收敛。

**直方图构建**：
- 将 attention scores z 映射到 [0,1] 区间，划分为 B 个等宽 bin
- 在 SRAM 上维护直方图 H，每个 bin 记录计数
- 存储开销 O(B)，与序列长度 n 无关

**理论保证**：
- 直方图目标函数 f_h(τ) 的根 τ_h 满足：τ* - h < τ_h ≤ τ*
- 近似误差 < 1/B，随 bin 数增加收敛到精确解

### 2. 安全混合求解器

根据 α 值选择不同的求解策略：
- α ∈ (1, 1.5]：Halley 步（f'' 有界，数值稳定）
- α ∈ (1.5, 2]：Newton 步（f' 行为良好，f'' 无界）
- α ≥ 2：割线步（f' 无界）
- 始终回退到二分法（保证收敛）

### 3. GPU 实现（Triton）

**4 阶段流程**：
1. **Phase 1 (最大值)**：流式计算每行的 max m_i
2. **Phase 2 (直方图)**：在 SRAM 上构建 B-bin 直方图，使用 bit-packing 避免原子操作
3. **Phase 3 (精炼)**：从 τ_h 开始，1 次迭代精炼；同时构建块掩码 M（bit-packing 编码）
4. **Phase 4 (输出)**：使用 GPU 原生 fns 指令遍历非零块，计算 O(|M|) 复杂度

**反向传播**：复用前向块掩码，仅遍历非零块，使用 fns 和 popc 指令。

### 4. 直方图容量

- 默认配置（w=64, B=8, Bc=64）：每查询块最大容量 16,320 个 key，足够 16K token
- 超长序列时使用周期性刷新

## 局限性

1. **短上下文开销**：前向 pass 在短上下文下可能比 FlashAttention-2 略慢（额外 τ 计算）
2. **稀疏度依赖**：加速效果依赖于块稀疏度，低稀疏度下无优势
3. **Triton 实现**：未利用 Hopper GPU 特性（如 TMA、WGMMA），有进一步优化空间
4. **直方图容量限制**：超长序列（>16K）需要额外刷新机制
5. **α 值选择**：需要根据任务选择 α，不同 α 值下收敛行为不同
6. **仅针对训练**：主要关注训练效率，对推理优化较少
