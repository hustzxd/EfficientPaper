LISA: Layerwise Importance Sampling for Memory-Efficient Large Language Model Fine-Tuning

一句话总结

LISA（Layerwise Importance Sampled AdamW）通过在训练过程中随机冻结大部分中间层、仅按重要性采样更新少量关键层，以接近 LoRA 的内存开销实现了超越 LoRA 和全参数微调的性能，是大语言模型高效微调的有力替代方案。

摘要翻译

自大语言模型（LLM）出现以来，机器学习领域取得了令人瞩目的进展，但其巨大的内存消耗已成为大规模训练的主要障碍。参数高效微调（PEFT）技术如低秩适配（LoRA）已被提出以缓解这一问题，但在大多数大规模微调设置中，其性能仍无法与全参数训练相媲美。为弥补这一不足，我们研究了 LoRA 在微调任务上的逐层特性，并观察到不同层之间权重范数存在不常见的偏斜分布。利用这一关键发现，我们发现了一种极其简单的训练策略，在广泛的设置中以与 LoRA 相当的内存成本超越了 LoRA 和全参数训练。我们将其命名为"逐层重要性采样 AdamW"（LISA），这是 LoRA 的一个有前途的替代方案，它将重要性采样的思想应用于 LLM 的不同层，并在优化过程中随机冻结大多数中间层。实验结果表明，在相似或更少的 GPU 内存消耗下，LISA 在下游微调任务中超越了 LoRA 甚至全参数调优，在 MT-Bench 分数上一致地超越 LoRA 11%-37%。在大规模模型上，特别是在 LLaMA-2-70B 上，LISA 在 MT-Bench、GSM8K 和 PubMedQA 上达到了与 LoRA 相当或更好的性能，证明了其在不同领域的有效性。

研究动机

大语言模型（如 ChatGPT）在文档生成、代码编写、问答和类人对话等任务中表现出色。随着 LLM 在各个任务领域的广泛应用，领域特定的微调已成为增强其下游能力的关键策略。然而，这些方法成本极高，给大规模模型的开发带来了重大障碍。

参数高效微调（PEFT） 技术（如适配器、提示权重、LoRA）被提出以减少可训练参数数量。其中，LoRA 是最广泛采用的 PEFT 技术之一，因为其允许适配器合并回基础模型参数的特性。但 LoRA 的性能在全参数微调上仍存在不足，特别是在大规模数据集的持续预训练中表现不佳。

核心观察： 作者研究了 LoRA 的逐层训练统计，发现 LoRA 的逐层权重范数存在不常见的偏斜分布——底部层和/或顶部层在更新中占据大部分权重，而其他自注意力层仅占很小的比例。这表明不同层在更新中具有不同的重要性。这一关键发现启发了"按重要性采样不同层"的思想，这恰好与重要性采样的思想相匹配。

1. 内存效率

实验设置： 使用 4× NVIDIA Ampere 架构 GPU（80GB 内存），单批次大小为 1，未使用梯度检查点、卸载或 Flash Attention 等其他内存节省技术。

关键结果： - LLaMA-2-70B： LISA E+H+2L 配置将峰值 GPU 内存从 LoRA Rank 128 的 79G 降低到 75G - LLaMA-2-7B： LISA 的内存降低使得在单个 RTX4090（24GB）GPU 上训练成为可能 - 速度提升： 相比全参数调优约 2.9× 加速，相比 LoRA 约 2× 加速 - 内存比较： LISA 在多个模型架构上系统性地减少了内存使用

2. 中等规模微调（MT-Bench）

数据集： Alpaca GPT-4（52K 训练实例）用于微调，MT-Bench（80 个高质量多轮问题）用于评估

关键结果（MT-Bench 平均分）： - TinyLlama： LISA (2.78) > FT (2.38) > LoRA (2.03) - Mistral-7B： LISA (5.23) > FT (4.94) > LoRA (4.71) - LLaMA-2-7B： LISA (5.42) > FT (5.10) > LoRA (4.86)

关键发现： - LISA 在 Writing、STEM 和 Humanities 领域一致地超越 LoRA 和全参数调优 - LISA 在需要记忆的任务中表现更好，而 LoRA 部分偏向推理任务 - LISA 相比 LoRA 一致提升 11%-37%（MT-Bench 分数）

  2. 性能优越： LISA 在多个任务上一致地超越 LoRA 和全参数微调，特别是在指令跟随任务中
  3. 简单有效： 算法设计极其简单，无需引入额外参数或复杂架构修改
  4. 理论保证： 具有收敛性理论保证，不改变损失目标
  5. 良好的兼容性： 与 DeepSpeed 等优化工具兼容，可用于训练 65B+ 参数的模型

局限

  1. 前向传播内存： LISA 与 LoRA 一样，在优化过程中前向传播仍需要模型在内存中，导致显著的内存消耗。这一限制可通过 QLoRA 等方法补偿。
  2. 随机性依赖： 虽然 LISA 对随机种子具有鲁棒性，但其性能仍依赖于采样策略。
  3. 超参数敏感性： 采样层数 和采样周期 对性能有显著影响，需要适当的超参数搜索。
  4. 理论假设： 收敛性保证基于凸损失函数假设，实际 LLM 训练中的非凸性可能导致理论与实践之间存在差距。
  5. 非最优采样策略： 当前的均匀随机采样策略可能不是最优的，考虑数据源和模型架构的重要性采样策略可能进一步提高效率。
  6. 应用场景有限： 目前主要在微调任务上验证，未涉及预训练等更大规模场景。
